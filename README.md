# Smart Study Planner

A Django-based web application developed to help students plan study schedules, manage subjects, track subtopics, and monitor study progress.

## Features
- User registration and login
- Add subjects and subtopics
- Assign due dates
- Automatic study hour calculation
- Subject-wise progress tracking
- Overall dashboard progress
- Custom logout success page

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite
